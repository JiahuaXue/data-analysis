# 📊 E-commerce Marketing Analytics

This project explores key customer response patterns in an e-commerce marketing dataset using descriptive statistics, hypothesis testing, and visual storytelling.

## 📌 Objective

To identify statistically significant differences in purchasing behavior across customer segments, and derive actionable marketing insights from data.

## 🧰 Tools Used

- Python (Pandas, Seaborn, Matplotlib, SciPy)
- Jupyter Notebook

## 🔍 Analysis Focus

- Customer segmentation by income, age, family size, and product affinity
- Statistical testing (t-tests, proportion tests) to compare group behaviors
- Data visualization to support key insights

## 📈 Highlights

- Found that high-income groups are significantly more responsive to luxury product categories.
- Customers with children showed distinct purchasing patterns compared to others.
- Identified meaningful interaction effects between education and product preference.

## 🧪 Sample Questions Addressed

- Are higher-income users more likely to purchase luxury items?
- Do married customers with children respond differently to campaigns?
- How does education level influence the likelihood of purchase?
