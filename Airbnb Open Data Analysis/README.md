# 🏠 Airbnb Open Data Analysis (NYC)

This project analyzes public Airbnb data in New York City to uncover pricing trends and hosting behaviors across different neighborhoods and property types.

## 📌 Objective

To identify which factors influence listing prices in NYC and provide data-driven recommendations for hosts or platform strategy.

## 🧰 Tools Used

- Python (Pandas, Seaborn, Matplotlib, Statsmodels)
- Jupyter Notebook

## 🔍 Analysis Focus

- Room type and neighborhood distributions
- Price variation across boroughs
- Influence of number of reviews, availability, and listing features on price

## 📈 Highlights

- Private rooms in Manhattan are 2x pricier on average than in the Bronx.
- Entire home/apt listings tend to receive higher ratings but are less available year-round.
- Regression analysis showed that room type and borough are the strongest predictors of price.

## 📊 Sample Visuals

- Heatmap of average prices by neighborhood
- Boxplots comparing price by room type
